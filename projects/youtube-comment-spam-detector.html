Overview01

Harmful comments reduce user trust, skew engagement metrics, and expose vulnerable viewers to scams and worse. This project classifies comments into four buckets, phishing_scam (crypto and messaging-app links), adult_bait (automated content traps), engagement_spam (repetitive "who is watching in 2026" patterns), and benign, so the harmful ones can be surfaced and handled.

How it works02

  1. Collect. Comments are pulled through the YouTube Data API.
  2. Label. Rule-based weak supervision flags obvious spam automatically, then a sampled set is validated by hand against clear guidelines.
  3. Engineer features. Behavioral markers are extracted: link density, emoji frequency, and repetition signatures.
  4. Train. A TF-IDF vectorizer feeds a logistic-regression baseline for multi-class classification, with an optional Streamlit dashboard on top.

Evaluation03

Because a missed scam is far costlier than a false alarm, the model is tuned for high precision on the high-risk categories (phishing and adult-bait), with confusion matrices and error analysis used to show where it succeeds and where it slips.
