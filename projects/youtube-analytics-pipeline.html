Overview01

A small data-engineering pipeline that systematically gathers and structures YouTube performance data, demonstrated on the top 50 videos for a search topic, so both quantitative engagement and qualitative sentiment can be analyzed downstream.

How it works02

  1. Extract. Connects to the YouTube Data API to pull video metadata and comments from top-performing content.
  2. Process. Structures views, likes, comment counts, and comment text into a consistent format.
  3. Store. Persists metrics and comments as JSON for downstream use.
  4. Analyze. Enables engagement-trend analysis and comment-level sentiment examination.

Design note03

A top-50 sampling strategy keeps the dataset meaningful while respecting API quota limits, and storing full comment text (not just counts) keeps the door open to sentiment work later.
